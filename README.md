## 🚀 Quick Start

### 1. Clone & Setup
```bash
git clone https://github.com/yourusername/tommy-portfolio.git
cd tommy-portfolio
npm install
```

### 2. Set API Key
```bash
export ANTHROPIC_API_KEY="sk-ant-your-key-here"
```

### 3. Run Locally
```bash
npm run dev
# Opens http://localhost:3000
```

### 4. Use Claude Code
```bash
# Ask Claude Code to improve your portfolio
claude-code "Add a dark mode toggle to the portfolio"

# Or run a pre-built script
npm run audit
npm run update-materials
```

## 🤖 Using Claude Code

Claude Code is a command-line tool that lets you ask Claude to update your portfolio directly from your terminal.

### Examples

**Improve design:**
```bash
claude-code "Add a testimonials section to the portfolio"
```

**Create features:**
```bash
claude-code "Create a blog system with markdown support"
```

**Automate tasks:**
```bash
claude-code "Create a script that generates job-specific CVs from job descriptions"
```

**Fix issues:**
```bash
claude-code "Make the portfolio fully accessible (WCAG AAA compliant)"
```

📖 **Full Guide:** See `CLAUDE_CODE_SETUP.md`

## 🌐 Deployment

### Option 1: Vercel (Recommended)

### Option 2: Netlify
```bash
npm install -g netlify-cli
netlify deploy
```

### Option 3: GitHub Pages
1. Push to `main` branch
2. Enable GitHub Pages in settings
3. Site lives at `username.github.io/tommy-portfolio`

### Option 4: Custom Domain
1. Buy domain (namecheap.com, etc.)
2. Point to Vercel/Netlify
3. Or upload HTML to your host

## 🎯 Job Search Workflow

### Using This Portfolio for Applications

1. **Find a job you like**
   ```bash
   # Ask Claude Code to customize portfolio
   claude-code "I found a SaaS marketing role. Customize the portfolio to highlight relevant experience from Genpact and Fujitsu"
   ```

2. **Generate custom CV**
   ```bash
   claude-code "Create a job-specific CV for this SaaS role: [paste job description]"
   ```

3. **Create cover letter**
   ```bash
   claude-code "Write a compelling cover letter for this role highlighting my marketing operations expertise"
   ```

4. **Track application**
   ```bash
   # Use your Notion job search system to track
   # Or let Claude Code help organize
   ```

### Template: Job-Specific Customization

```bash
claude-code "I'm applying for a [ROLE] position at [COMPANY].

Job requirements:
- [Key requirement 1]
- [Key requirement 2]
- [Key requirement 3]

From my experience, highlight:
1. Which of my roles best match (Lava, Reality+, Genpact, Fujitsu, Kroll)
2. Specific achievements that demonstrate these skills
3. How my approach aligns with their needs

Then:
1. Create a customized version of my portfolio emphasizing these points
2. Generate a job-specific CV
3. Draft a cover letter that connects my story to their role"
```
